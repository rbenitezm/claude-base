# Imágenes de comprobación

> una imagen de prueba enviada por chat parece un entregable: decir siempre «no es para subir» y mirar qué fichero hay de verdad antes de diagnosticar

(de claude-base) En ODA (11-sep-2026) se envió un recorte de un PDF para enseñar que el título salía entero, y Raúl lo subió como arte del lomo: la cubierta volvió a salir mal.

**Why:** una imagen adjunta en el chat parece un entregable si no se dice lo contrario.

**How to apply:** cualquier fichero de comprobación va con «solo para ver, no es un fichero para subir». Si sí es un entregable, decir dónde subirlo. Antes de diagnosticar «seguimos igual», mirar qué fichero hay de verdad (tamaño, fecha) y no suponer que es el que el usuario cree.
